# dietolog_client — руководство пользователя

Краткое описание текущего Angular-приложения «Диетолог».  
При изменении UI обновлять этот файл и выкладывать в репозиторий вместе с кодом (см. `.cursor/rules/project-context.mdc`).

**Репозиторий:** https://github.com/RobinZGit/dietolog_client  

---

## Назначение

Подобрать набор продуктов (граммы) так, чтобы суммарные нутриенты попадали в суточные нормы (min / max). Можно исключать продукты и нутриенты, смотреть «спектр» вклада и сохранять раскладку.

---

## Запуск

```bash
npm install
npm start
```

Открыть адрес, который покажет Angular CLI (обычно `http://localhost:4200/`).

Опционально для режима с сервером: поднять `dietolog_server` на `http://localhost:8080` и в коде выставить `localData = false` (по умолчанию данные берутся из встроенного снимка).

## Экран: продукты и нутриенты

Две основные таблицы: **Продукты** (слева) и **Нутриенты** (справа).

### Продукты

| Элемент | Смысл |
|---------|--------|
| Поле количества (гр.) | Сколько продукта в раскладке |
| Кнопка `>` у продукта | Добавить «оптимальное» количество продукта |
| Чекбокс «Исключен» | Продукт не участвует в расчёте (количество обнуляется) |
| «спектр» | Вклад нутриентов выбранного продукта |
| Фильтр по подстроке | Поднять в списке продукты с текстом в имени (`\|` = ИЛИ) |
| Сортировка по нутриенту | Затем сортировать по содержанию выбранного нутриента |
| Подсветка рекомендованных | Число топ-продуктов на нутриент |
| ADD | Добавить один из рекомендованных продуктов |
| Save | Выгрузить конфигурацию (Excel / сценарий сохранения) |
| Загрузка `.dtlg` | Восстановить сохранённую раскладку из файла |
| Выпадающий список исключений | Включить все / исключить ненулевые / скоромное / до рыбы / до масла |

Итоговый вес выбранных продуктов показывается в шапке таблицы продуктов.

### Нутриенты

| Элемент | Смысл |
|---------|--------|
| Текущее значение | Сумма нутриента по раскладке (на выбранные граммы) |
| min / max | Суточная норма (редактируется) |
| Кнопки `<` у норм | Подобрать продукт и выставить количество нутриента к min/max |
| `1:N` | Пропорционально изменить количества выбранных продуктов под min-норму |
| Чекбокс «Исключен» | Нутриент не участвует в подсказках/оптимизации |
| «развернуть» | Дерево продуктов с этим нутриентом |
| «спектр» | Вклад продуктов в нутриент |
| Ссылка info | Справка на edaplus.info (если задана) |

Цветовая подсветка строк отражает, в норме ли нутриент, ниже min или выше max (см. классы в компоненте).

## Сохранение состояния в браузере

При изменениях раскладка пишется в `localStorage` (ключи вида `rz_dietolog_configuration_*`: продукты, нутриенты, параметры). После перезагрузки страницы состояние восстанавливается, если ключи есть.

---

## Данные

- Встроенный снимок: ~43 нутриента, ~1231 продукт, ~26k связей состав/100 г.
- По ряду микроэлементов (в т.ч. **йод**) значения есть **не у всех** продуктов — это ограничение исходной таблицы, а не «отсутствие нутриента в списке».
- Планируется более релевантное дополнение sparse-нутриентов и хранение в IndexedDB для упрощённого HTML-клиента (см. `docs/PROJECT_CONTEXT.md`).
