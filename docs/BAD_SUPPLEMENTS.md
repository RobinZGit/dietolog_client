# Секция БАД (биологически активные добавки)

## Зачем

Отдельная группа продуктов: популярные дозировки **йода, кальция, железа** (плюс селен и витамин D).  
В списке помечаются `fastdegree = "БАД"`.

## Компания

Сейчас в именах стоит шаблон **`БАД-шаблон`**.  
Когда выберете конкретный бренд — задайте его в `scripts/add-bad-supplements.py` (`COMPANY = "..."`) и перезапустите скрипт.

## Как считается количество

Формула Angular: `нутриент += кол-во * value / 100`.

Для БАД:
- **кол-во** = число таблеток/капсул (в UI «гр.» означает **шт.** для БАД);
- **value** в `info` = **доза_в_1_шт × 100** (чтобы 1 шт. давала ровно дозу).

Пример: йод 100 мкг/табл. → `value = 10000`.

## Состав шаблона (сейчас)

| Продукт | Нутриент | На 1 табл. |
|---------|----------|------------|
| Йод 100 / 200 мкг | Йод (I) | 100 / 200 мкг |
| Кальций 500 / 1000 мг | Кальций | 500 / 1000 мг |
| Железо 10 / 20 мг | Железо | 10 / 20 мг |
| Селен 50 мкг | Селен | 50 мкг |
| Витамин D 10 мкг | Витамин D | 10 мкг |

## Группы в данных

Поле `group` есть **только у БАД** (например `БАД · Йод`). У обычных продуктов групп нет — в простом HTML они идут плоским списком.

## Где смотреть в UI

- **Простой HTML (v7+):** вкладки Все / Продукты / **БАДы**; у БАД — иерархия группа → продукт
- **Angular:** фильтр исключений «Исключить БАД» / «Только БАД»
