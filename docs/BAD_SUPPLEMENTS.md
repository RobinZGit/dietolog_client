# Секция БАД (биологически активные добавки)

## Зачем

Отдельная категория продуктов: популярные дозировки витаминов и минералов для добора рациона (особенно в `mode=layout`).

## Группы в данных

- У **всех** продуктов есть поле **`group`** — см. `docs/FOOD_GROUPS.md`.
- У **всех БАД** `group` = **`БАД`** и `fastdegree` = **`БАД`** (одна группа, без подразделов).

## Где смотреть в UI

- **Простой HTML (v13+):** поиск; группа **БАД**; в `mode=layout` демо-URL без БАД; примеры **1–2** без БАД, пример **3** — с БАДами.
- **Angular:** «Исключить БАД» / «Только БАД»

## Компания

Сейчас в именах стоит шаблон **`БАД-шаблон`**.  
Когда выберете бренд — `COMPANY` в `scripts/add-bad-supplements.py` и перезапуск скрипта.

## Как считается количество

Формула Angular: `нутриент += кол-во * value / 100`.

Для БАД:
- **кол-во** = число таблеток/капсул/батончиков (в UI «гр.» → **шт.** для БАД);
- **value** в `info` = **доза_в_1_шт × 100**.

Пример: йод 100 мкг/табл. → `value = 10000`.  
Магний B6 — две строки `info` (Mg + B6) на один продукт.

## Состав шаблона (v13, 34 позиции)

Витамины/минералы (как в v12) + масла/омега **только если нет в каталоге еды**:

| Продукт | Форма | Нутриент(ы) | На 1 шт. |
|---------|-------|-------------|----------|
| … витамины/минералы (30 шт., см. v12) | табл. | … | … |
| Омега-3 1000 мг (EPA+DHA) | капс. | Жиры + E | 1 г + 5 мг |
| Омега-3 батончик | бат. | Жиры + E | 3 г + 5 мг |
| Тыквенное масло 1000 мг | капс. | Жиры + E | 1 г + 3 мг |
| Масло виноградных косточек 1000 мг | капс. | Жиры + E | 1 г + 10 мг |

**Не** добавляли в БАД (уже есть как продукты): рыбий жир, жир/масло печени трески, оливковое, льняное, подсолнечное, кунжутное, кокосовое и др.  
Отдельного нутриента «Омега-3» в БД нет — учёт через **Жиры** (+ E).

Пересборка: `python scripts/add-bad-supplements.py` → `python scripts/build-simple-dietolog.py`.
