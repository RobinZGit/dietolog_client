# Секция БАД (биологически активные добавки)

## Зачем

Отдельная категория продуктов: популярные дозировки **йода, кальция, железа, магния, магния B6** (плюс селен и витамин D).

## Группы в данных

- У **всех** продуктов есть поле **`group`** (пищевая таксономия) — см. `docs/FOOD_GROUPS.md`.
- У **БАД** `group` = `БАД · Йод` / `БАД · Магний` / … (и то же в `fastdegree` для фильтра `startsWith('БАД')`).

## Где смотреть в UI

- **Простой HTML (v9+):** группа → продукт; вкладки Все / Продукты / БАДы
- **Angular:** «Исключить БАД» / «Только БАД»

## Компания

Сейчас в именах стоит шаблон **`БАД-шаблон`**.  
Когда выберете бренд — `COMPANY` в `scripts/add-bad-supplements.py` и перезапуск скрипта.

## Как считается количество

Формула Angular: `нутриент += кол-во * value / 100`.

Для БАД:
- **кол-во** = число таблеток/капсул (в UI «гр.» → **шт.** для БАД);
- **value** в `info` = **доза_в_1_шт × 100**.

Пример: йод 100 мкг/табл. → `value = 10000`.  
Магний B6 — две строки `info` (Mg + B6) на один продукт.

## Состав шаблона (сейчас)

| Продукт | Нутриент(ы) | На 1 табл. |
|---------|-------------|------------|
| Йод 100 / 200 мкг | Йод (I) | 100 / 200 мкг |
| Кальций 500 / 1000 мг | Кальций | 500 / 1000 мг |
| Железо 10 / 20 мг | Железо | 10 / 20 мг |
| Селен 50 мкг | Селен | 50 мкг |
| Витамин D 10 мкг | Витамин D | 10 мкг |
| Магний 200 / 400 мг | Магний (Mg) | 200 / 400 мг |
| Магний B6 | Mg + витамин B6 | 50+5 / 100+10 мг |

## Где смотреть в UI

- **Простой HTML (v8+):** вкладки Все / Продукты / **БАДы**; у БАД — иерархия по `fastdegree` → продукт
- **Angular:** «Исключить БАД» / «Только БАД»
