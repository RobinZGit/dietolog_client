# Аудит шкал нутриентов (v11)

**Дата:** 2026-07-30  
**Источники сравнения:** USDA FoodData Central (яйцо FDC ~171287 и аналоги), USDA/FDA/ODS Iodine DB R4, обзоры dietary silicon (Pennington / MDPI Appl. Sci. 2020).

## Пример `mode=layout` (параметр 2)

Продукты: яйцо целое, гречиха зерно, молоко сухое 1%, крупа рисовая.

| Продукт | Вывод |
|---------|--------|
| Яйцо | Макросы/Ca/P/Mg/K/Zn/D ≈ USDA (ratio ~0.9–1.5). Йод был 20 мкг → **49** (Iodine DB). Холестерин 570 vs USDA 372 — типично для части русскоязычных таблиц. |
| Гречиха | Mg/P/Zn/ккал OK. Fe 8.3 vs USDA ~2.2 — **завышен** в исходной таблице (не трогали массово). **Si был 120 мг → 1.2 мг** (÷100). |
| Рис | Макросы OK. **Si был 100 мг → 1.0 мг** (лит. белый рис ~1.2 мг/100 г). |
| Молоко сухое | Высокие Ca/B12 на 100 г ожидаемы для порошка. |

«Странности» в рекомендациях layout раньше усиливал **кремний** (срок «14 суток» с 150 г гречки) и ошибки единиц Mn/Cu/B5.

## Системные ошибки единиц

| Нутриент | Было | Стало | Почему |
|----------|------|-------|--------|
| Марганец (Mn) | units **мкг**, min 5000; значения как **мг** (яйцо 0.03) | **мг**, min **5** | USDA Mn яйца ~0.03 мг |
| Медь (Cu) | мкг / 1500; значения в мг | **мг**, min **1.5** | USDA Cu яйца ~0.07 мг |
| Витамин В5 | мкг / 5000; значения в мг | **мг**, min **5** | пантотенат яйца ~1.3–1.5 мг |

## Масштаб кремния

Зерновые в базе давали 100–1240 мг Si/100 г. Литература: белый рис **~1.2 мг**, отруби до ~10 мг. Для всех **не-БАД** значений Si применено **÷100** (28 строк `info`).

## Точечные правки (явный ×100 / мусор)

| Продукт | Нутриент | Было → Стало |
|---------|----------|--------------|
| Ячмень, лущеный | B2 | 28 → **0.28** мг (USDA ~0.285) |
| Фейхоа | Zn | 40 → **0.06** мг (USDA ~0.06) |
| Яйцо куриное, целое | I | 20 → **49** мкг |

## Что выглядит «огромным», но не баг

- **БАДы:** в `info.value` хранится **доза×100** (см. `docs/BAD_SUPPLEMENTS.md`) — при сравнении «на 100 г» выглядит как ×100.
- Печень / устрицы / рыбий жир — реально высокие A, B12, Zn, D.
- Соль / нори — высокий Na/I ожидаем.
