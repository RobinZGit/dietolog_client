# Пищевые группы продуктов (`products.group`)

Научная (рацион / FAO-подобная) классификация всех продуктов в поле **`group`**.

Постная шкала **`fastdegree`** (`сухоядение` / `скоромное` / …) **не меняется** — она для фильтров поста в Angular.

## Группы еды

| Группа | Примеры |
|--------|---------|
| Молочные продукты | молоко, сыр, творог, йогурт… |
| Рыба и морепродукты | треска, сельдь, креветки… |
| Овощи | картофель, капуста, морковь… |
| Фрукты и ягоды | яблоки, цитрусы, ягоды, варенье… |
| Зерновые и хлеб | хлеб, крупы, мука, макароны… |
| Напитки | вода, соки, чай, кофе, алкоголь… |
| Мясо и мясные продукты | говядина, свинина, колбаса… |
| Птица | курица, индейка, утка… |
| Специи и приправы | соль, горчица, пряности… |
| Орехи и семена | арахис, миндаль, семена… |
| Бобовые | горох, фасоль, чечевица, соя… |
| Сахар и сладости | сахар, шоколад, конфеты… |
| Жиры и масла | масла, маргарин, майонез… |
| Яйца | яйцо, омлет, желток… |
| Грибы | шампиньоны, белые… |
| Готовые блюда | супы, запеканки… (если не попало в сырьё) |
| Прочее | неклассифицированное (сейчас 0) |

## БАД

Остаются своими группами: `БАД · Йод`, `БАД · Магний`, `БАД · Магний B6`, …

## Пересчёт

```bash
python3 scripts/assign-product-groups.py
python3 scripts/build-simple-dietolog.py
```

Правила — по подстрокам имени (`scripts/assign-product-groups.py`). При новых продуктах при необходимости дополняйте `RULES`.
