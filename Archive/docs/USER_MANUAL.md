# dietolog_client — руководство пользователя

Краткое описание приложений «Диетолог».  
При изменении UI обновлять этот файл и выкладывать в репозиторий вместе с кодом (см. `.cursor/rules/project-context.mdc`).

**Репозиторий:** https://github.com/RobinZGit/dietolog_client

## Два интерфейса

| Интерфейс | Зачем |
|-----------|--------|
| **Angular** (`ng serve`) | Полная раскладка рациона, нормы, спектры, сохранение `.dtlg` |
| **Простой HTML** [`simple/dietolog.html`](../simple/dietolog.html) | Быстрый просмотр: продукты → нутриенты; БАДы — группа → продукт (IndexedDB) |

На форме Angular ссылки на `simple/dietolog.html`:
- под заголовком **«ДИЕТОЛОГ»** — «Открыть простой просмотр (IndexedDB) →»;
- в зелёной панели фильтров рядом с **ADD** — кнопка **«Простой HTML»**.

- **GitHub Pages:** https://robinzgit.github.io/dietolog_client/simple/dietolog.html  
- Локально / `ng serve`: `/simple/dietolog.html`

## Простой просмотр (`simple/dietolog.html`)

1. Откройте **один файл** `dietolog.html` (или ссылку). Версия снимка видна в заголовке. Вся БД уже внутри файла (`SEED`).
2. Список сразу из встроенного снимка; **IndexedDB** обновляется в фоне.
3. Сразу поле **поиска** (часть имени или группы; `|` = ИЛИ). Вкладок Все/Продукты/БАДы нет.
4. Сначала **группа** (овощи, мясо, …, одна группа **БАД**) → продукт → нутриенты (100 г; для БАД — на 1 шт.).
5. Продукты внутри группы подгружаются при раскрытии.
6. При смене версии снимка IndexedDB перезаливается в фоне.

### Режимы по GET (опубликованная ссылка)

База: https://robinzgit.github.io/dietolog_client/dietolog.html

| Режим | Пример |
|-------|--------|
| Обычный | без параметров — на форме ссылки на режимы ниже |
| Нутриенты | `?mode=nutrients` — список нутриентов; раскрытие → топ‑15 продуктов + % суточной нормы |
| Раскладка | `?mode=layout&items=yajco_kurinoe_celoe:100,grechiha_zerno:150&days=1` |
| Раскладка Насти | на главной — ссылка «Раскладка Насти» (сушёные овощи + база) |
| Раскладка + пост | `…&fastdegree=сухоядение` (или `до масла` / `до рыбы` / `скоромное`) |

**Строка продуктов:** латинские slug через запятую `имя:граммы` (читаемо в URL без «каши» из percent-encoding). Можно JSON `[{"n":"slug","g":100}]` или точный `id:193:100`.  
**Срок:** `days` (или `time`) — на сколько суток раскладка (по умолчанию 1).  
**Степень поста:** `fastdegree` (алиасы `fast` / `post`). По умолчанию **не задана** — все продукты. Шкала строже→мягче: сухоядение → до масла → до рыбы → скоромное. В форме раскладки выбор стоит рядом со сроком; при смене убираются неподходящие продукты и пересчитываются рекомендации (БАД всегда допустимы).  
В анализе показываются **исходное имя из ссылки** и **ближайший русский продукт** из базы.  
Длительность рациона оценивается по нутриенту с максимальным покрытием суточной нормы; по остальным считается дефицит; рекомендуются добавки и несколько примеров более полной раскладки.

Это **минимальный** UI плюс два GET-режима; полный расчёт рациона — в Angular.

## Angular: продукты и нутриенты

### Запуск

```bash
npm install
npm start
```

Обычно `http://localhost:4200/`. Опционально сервер `dietolog_server` на `:8080` при `localData = false`.

### Продукты

| Элемент | Смысл |
|---------|--------|
| Поле количества (гр.) | Сколько продукта в раскладке |
| Кнопка `>` у продукта | Добавить «оптимальное» количество продукта |
| Чекбокс «Исключен» | Продукт не участвует в расчёте |
| «спектр» | Вклад нутриентов выбранного продукта |
| Фильтр по подстроке | Поднять в списке (`\|` = ИЛИ) |
| Сортировка по нутриенту | По содержанию выбранного нутриента |
| ADD | Добавить рекомендованный продукт |
| Save / `.dtlg` | Выгрузка / загрузка раскладки |

### Нутриенты

Текущее значение по раскладке, min/max нормы, исключение, разворот дерева продуктов, спектр, ссылки edaplus.info.

### Состояние в браузере

`localStorage` ключи `rz_dietolog_configuration_*`.

## БАДы

Отдельная секция добавок (`fastdegree=БАД`): йод, кальций, железо и др.  
В простом HTML — группа **БАД**; в Angular — фильтр «Только БАД» / «Исключить БАД».  
Количество для БАД = **штуки** (таблетки). Подробности: `docs/BAD_SUPPLEMENTS.md`.

## Данные

- Снимок: ~43 нутриента, ~1233 продукта, ~26.4k значений на 100 г.
- **Йод:** дополнен из USDA/FDA/ODS Iodine DB R4 — покрытие ~18% продуктов (было ~10%); детали в `docs/IODINE_ENRICHMENT.md`.
- Другие микроэлементы (V, Si, B, D, Cr…) по-прежнему разрежены; полный импорт USDA SR Legacy не делался.
